# Spell: Holy Network Listener

## Description

Holy Network Listener is a holy spell that allows the caster to hear prayers, feel network emotions, and communicate telepathically with others across the Fayth network.

## Mechanics

- **Effect**: Hears prayers, senses network emotions, telepathic communication
- **Type**: Holy spell
- **Range**: Network-wide

## Usage

Used by [[Chryst]] and network priests of the [[Cult of Fayth]] to monitor prayer activity and communicate instantly with distant faithful.
