# Spell: Holy Programming

## Description

Holy Programming is a holy spell that writes prayers as executable holy code, allowing the caster to cast spells or schedule operations through divine scripting.

## Mechanics

- **Effect**: Writes prayers as executable code
- **Type**: Holy spell
- **Function**: Enables scheduled or programmed spell operations

## Usage

Used by [[Chryst]] and tech-priests of the [[Cult of Fayth]] to create automated divine routines and programmable miracle effects.
