# Spell: Event Horizon

## Description

Event Horizon is a void passive ability where the user's shield contains a miniature void singularity that bends magical projectiles away from the user.

## Mechanics

- **Effect**: Shield contains miniature void singularity that bends magical projectiles
- **Type**: Void passive
- **Defense**: Projectile deflection

## Usage

Possessed by [[Styllfried]] and advanced void mages whose shields generate localized gravity wells that protect against magic.
